# Admin
Dies ist die Seite (Dashboard) für den Admin. Es benötigt einen Code, bereitgestellt von `/api`'s SECRETS, um auf dieses zuzugreifen. Der Admin kann die Zeit festlegen, starten, stoppen, alle Bilder live einsehen und die Anzahl der gemalten Bilder sehen. Zudem kann man dadurch auch das Raten starten, indem eine andere Person außer der Teilnehmer ein Bild sieht und es erraten kann.
